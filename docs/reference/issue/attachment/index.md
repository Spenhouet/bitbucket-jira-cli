# bj issue attachment

List and download issue attachments.

## Synopsis

```
bj issue attachment <command> [OPTIONS]
```

## Commands

| Command | Description |
| --- | --- |
| [`list`](list.md) | List the attachments on an issue. |
| [`download`](download.md) | Download issue attachments (all of them unless filtered). |
