# bj webhook delete

Delete a webhook.

## Synopsis

```
bj webhook delete [OPTIONS] UID
```

## Arguments

| Argument | Description |
| --- | --- |
| `UID` | Webhook uuid. _(required)_ |

## Options

| Option | Description |
| --- | --- |
| `-R, --repo <text>` | WORKSPACE/REPO. |
| `-W, --workspace <text>` | Operate on a workspace's webhooks instead. |
| `-y, --yes` | Skip the confirmation prompt. |
