# bj repo deploy-key

Manage repository access/deploy keys.

## Synopsis

```
bj repo deploy-key <command> [OPTIONS]
```

## Commands

| Command | Description |
| --- | --- |
| [`list`](list.md) | List a repository's access keys. |
| [`add`](add.md) | Add an access key to a repository. |
| [`delete`](delete.md) | Delete a repository access key. |
