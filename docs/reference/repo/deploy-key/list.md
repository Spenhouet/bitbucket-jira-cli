# bj repo deploy-key list

List a repository's access keys.

## Synopsis

```
bj repo deploy-key list [OPTIONS]
```

## Options

| Option | Description |
| --- | --- |
| `-R, --repo <text>` | WORKSPACE/REPO (default: git remote). |
| `--json` | Output raw JSON. |
| `-q, --jq <text>` | Filter JSON with a jq expression. |
