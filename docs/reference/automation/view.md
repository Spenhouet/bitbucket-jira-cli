# bj automation view

View one rule; --json prints its full definition.

## Synopsis

```
bj automation view [OPTIONS] UUID
```

## Arguments

| Argument | Description |
| --- | --- |
| `UUID` | Rule UUID (see `bj automation list`). _(required)_ |

## Options

| Option | Description |
| --- | --- |
| `--json` | Output raw JSON. |
| `-q, --jq <text>` | Filter JSON with a jq expression. |
