# bj automation export

Export a rule definition as JSON, ready for `bj automation import`.

## Synopsis

```
bj automation export [OPTIONS] UUID
```

## Arguments

| Argument | Description |
| --- | --- |
| `UUID` | Rule UUID (see `bj automation list`). _(required)_ |

## Options

| Option | Description |
| --- | --- |
| `-o, --output <path>` | Write to this file instead of stdout. |
