# bj automation delete

Delete a rule. Jira only deletes disabled rules.

## Synopsis

```
bj automation delete [OPTIONS] UUID
```

## Arguments

| Argument | Description |
| --- | --- |
| `UUID` | Rule UUID (see `bj automation list`). _(required)_ |

## Options

| Option | Description |
| --- | --- |
| `-y, --yes` | Skip the confirmation prompt. |
