# bj automation disable

Disable a rule.

## Synopsis

```
bj automation disable [OPTIONS] UUID
```

## Arguments

| Argument | Description |
| --- | --- |
| `UUID` | Rule UUID (see `bj automation list`). _(required)_ |

## Examples

```bash
bj automation disable 0192e5ac-0e25-71de-ba7b-d972e6a2049a
```
