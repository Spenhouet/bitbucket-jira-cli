# bj pr task

Manage pull-request tasks (checklist items).

## Synopsis

```
bj pr task <command> [OPTIONS]
```

## Commands

| Command | Description |
| --- | --- |
| [`list`](list.md) | List a pull request's tasks. |
| [`add`](add.md) | Add a task to a pull request. |
| [`resolve`](resolve.md) | Mark a task resolved. |
| [`unresolve`](unresolve.md) | Mark a task unresolved. |
| [`edit`](edit.md) | Edit a task's text. |
| [`delete`](delete.md) | Delete a task. |
