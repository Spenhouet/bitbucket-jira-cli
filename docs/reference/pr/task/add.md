# bj pr task add

Add a task to a pull request.

## Synopsis

```
bj pr task add [OPTIONS]
```

## Options

| Option | Description |
| --- | --- |
| `-b, --body <text>` | Task text. |
| `--comment <integer>` | Attach to a comment id. |
| `-e, --editor` | Write in $EDITOR. |
| `--pr <integer>` | PR id (default: current branch). |
| `-R, --repo <text>` | Target repo as WORKSPACE/REPO. |
