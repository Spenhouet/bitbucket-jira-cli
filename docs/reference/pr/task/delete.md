# bj pr task delete

Delete a task.

## Synopsis

```
bj pr task delete [OPTIONS] TASK_ID
```

## Arguments

| Argument | Description |
| --- | --- |
| `TASK_ID` | Task id. _(required)_ |

## Options

| Option | Description |
| --- | --- |
| `-y, --yes` | Skip the confirmation prompt. |
| `--pr <integer>` | PR id (default: current branch). |
| `-R, --repo <text>` | Target repo as WORKSPACE/REPO. |
