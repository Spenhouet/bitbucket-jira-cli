# bj pr task list

List a pull request's tasks.

## Synopsis

```
bj pr task list [OPTIONS]
```

## Options

| Option | Description |
| --- | --- |
| `--pr <integer>` | PR id (default: current branch). |
| `-R, --repo <text>` | Target repo as WORKSPACE/REPO. |
| `--json` | Output raw JSON. |
| `-q, --jq <text>` | Filter JSON with a jq expression. |
